# Amazon Clone

Full‑stack Amazon clone built with React, Node.js, Express, MongoDB.

## Project Demo

check out the [Live Video Walkthrough on Loom] (https://www.loom.com/share/da7d90cf4d2546e3b9a54259d7ea99f1)

## Features

- User authentication (login/register)
- Product listing and search
- Add to cart and checkout
- Order history

## Tech Stack

- Frontend: React, Context API, Axios
- Backend: Node.js, Express
- Database: MongoDB
